## PID 与斜坡

`robot_debug.hpp` 的 PID 参数为 `(kp, ki, kd)`，可通过调试器调整；输出和积分限幅在 PID 对象构造时确定。

| 配置 | 数字 | 当前用途 |
| --- | --- | --- |
| `len_startup` | `{5000, 0, -100}` | 启动状态腿长 PID |
| `len_run` | `{2000, 0, -400}` | NORMAL/SPIN 腿长 PID；NORMAL 的腿长输出实际改由腿高 LQR 负责 |
| `roll` | `{0.5, 0, 0}` | SPIN 横滚 PID |
| `phi_recover` | `{20, 0, 10}` | RECOVER 翻身腿角 PID，来自 `wbr_2026` |
| `phi_flatten_fast` | `{10, 0, 5}` | 展腿快速段角度 PID |
| `phi_flatten_slow` | `{5, 0, 10}` | 展腿慢速段角度 PID |
| `phi_neutral` | `{30, 0, 10}` | NEUTRAL 腿角 PID |

输出及积分限幅分别为：腿长 PID `125 / 0`，横滚 PID `0.05 / 0.005`，腿角 PID `40 / 0.005`。

这些值来自迁移源，不应据此认为经过当前硬件验证；`wbr_2026` 中有不同的 PID 数值。PID 构造现在直接读取对应参数组：腿长使用 `len_startup`，横滚使用 `roll`，腿角初始使用 `phi_flatten_slow`。进入相关控制状态后仍按原有逻辑更新参数，不清除 PID 历史。
